# Muhammed Nur - Professional Portfolio

A high-end, cybernetic-themed portfolio website for a Computer Engineer & Full-Stack Developer. Built with HTML5 and Tailwind CSS, featuring a responsive design and modern animations.

## 🛠 Tech Stack
*   **Core**: HTML5, Tailwind CSS (CDN).
*   **Icons**: Lucide Icons.
*   **Theme**: Cybernetic Dark (Slate/Cyan/Teal).
*   **Font**: Inter (Google Fonts).

## ✨ Key Features
*   **Cybernetic Design**: A sleek dark theme with cyan accents and gradient text.
*   **Responsive**: Fully optimized for mobile, tablet, and desktop screens.
*   **Skills Visualization**: Categorized into System Programming and Web Technologies with visual progress bars.
*   **Project Placeholders**: Ready-to-use cards for showcasing major web projects with GitHub links.
*   **Contact Form**: Integrated Formspree support for serverless email handling.

## 🌍 How to Deploy (GitHub Pages)
1.  Create a new repository on GitHub (e.g., `portfolio`).
2.  Upload `index.html` and `README.md`.
3.  Go to **Settings** > **Pages**.
4.  Select `main` branch and `/ (root)` folder.
5.  Click **Save**.

## 🎨 Customization
*   **Projects**: Edit the "Major Web Projects" section in `index.html` to add your real project details.
*   **Contact**: Replace `YOUR_FORM_ID` in the form action URL with your actual Formspree ID.
*   **Links**: Update the `href` attributes for GitHub and LinkedIn in the footer.
